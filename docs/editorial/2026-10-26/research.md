# Source checks for the 26 October content release

Holmen recommends 45–60% relative humidity and 20–23°C for its paperboard printing/converting guidance. This is a processing recommendation, not a finished chocolate-box storage specification.[1]
RISE describes moisture-driven dimensional changes in paper and paperboard, including curl and waviness.[2]

The following original references were reopened to check the attribution retained in the eight edited analyses. Avery Dennison discusses Lost Barrels and EDIT (036).[3]
