# 整套定制包装实施计划

目标：客户先选主包装，再配置配套，统一提交一套可审核的需求，减少分别采购和重复沟通。

1. 四大业务分类 → 结构家族 → 变体。保留现有 12 个模型；未支持的结构只提供咨询，不能冒用其他模型。
2. 增加纸袋、丝带/蝴蝶结、卡片、吊牌、贴纸、薄页纸、运输包装。内托继续使用现有独立字段。
3. 每项填写尺寸、材料、印刷、工艺、每套数量和其他要求；可指定沿用主包装品牌设计。
4. 配套数量随主包装套数变化；未核价标为待报价。袋子/外箱适配必须核对成品外尺寸，不能拿内尺寸保证装得下。
5. 统一纳入本地保存、版本复制、JSON 导入导出、方案书、表单和 WhatsApp 草稿。
6. 测试旧功能和新数据流、检查移动布局，打包发布。

后续阶段：按真实生产参数逐项建立附件可视模型、自动尺寸匹配和供应商核准的参考价格。本期不把文字规格伪装为附件 3D 效果，也不自动发送客户消息。
