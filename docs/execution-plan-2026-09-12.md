# MTT organic growth execution plan

No additional paid services. Preserve existing URLs, source projects, working editor features and private customer data.

## Round 1 — fragrance procurement path
- Inspect Search Console exclusions; separate intentional resource 404s and canonical alternatives from lost content. Do not redirect development resources to the homepage.
- Improve existing fragrance page with box / insert / matching bag links and stage-specific paths: final bottle measurements → design; product in development → consultation.
- Publish a distinct coordinated box-and-bag planning guide, not another duplicate insert article. Label concept visuals; no invented case studies or customer endorsements.
- Validate build, internal links, mobile/desktop layout and contact destinations without sending test enquiries. Deploy through existing GitHub Pages archive and verify live content.
- Request indexing of the updated fragrance page and new guide after release; record actual Google responses privately.

## Subsequent rounds — daily evidence-driven work
- Resolve verified crawl/access failures; inspect discovered/crawled exclusions for unique content and internal links. Record report dates and avoid repeated requests for unchanged URLs.
- Establish GA4 conversion definitions: clicks differ from received enquiries; accepted form submissions differ from orders. GA4 stream was verified active; do not recreate it.
- Upgrade the design tool incrementally: selected structure accuracy, artwork placement, finish preview, mobile workflow, and specification handoff. Test each affected feature before release.
- Add real production cases only from approved photos/specifications with permission to publish. Until assets exist, improve product detail and clearly labelled planning examples.
- Weekly compare complete periods of relevant query impressions/clicks, tool usage and user-confirmed qualified enquiries. No guaranteed ranking or lead count.

## Case material needed
Approved product/sample images, actual structure and material, finish details, sample review observations, and permission for any customer identity. Never use private WhatsApp attachments as public marketing assets by default.
