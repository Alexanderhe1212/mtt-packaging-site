# User-supplied structure reference — implementation mapping

Separate three dimensions instead of treating every term as an exclusive box family.

| Reference | Classification | Current rigid phase |
|---|---|---|
| Reverse tuck | Folding-carton opening | Excluded |
| Aircraft/mailer | Typically corrugated folding construction | Excluded |
| Lift-off lid | Opening | Detached lid/base; square, rectangle, round or shaped |
| Drawer | Opening | Rigid sleeve plus sliding tray |
| Polygon / irregular shape | Outline | Must retain matching lid/base geometry |
| Window | Feature | Only with a specified structural opening and film option |
| Handle | Feature | Separate attachment and load review |
| Hanging | Retail-display feature | Reserved for an appropriate retail construction |
| Display | Presentation function | Do not infer the underlying opening from this label |
| Book | Opening | Rigid panel with a real spine/hinge and optional concealed magnets |
| Double door | Opening | Symmetric attached doors, correctly sized to meet |
| Collapsible | Construction | A collapsible rigid box is distinct from a folding carton |
| Rotating | Mechanism | Requires an explicit pivot and clearance design before inclusion |

The reference's general statements about price, compression strength, automatic production and print limitations are not product-specific evidence and must not be copied into claims. Geometry and materials must be reviewed for the particular design.
