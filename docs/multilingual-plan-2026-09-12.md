# MTT 全球客户语言适配计划

现状：44 个站点地图页面；正文、菜单、询价组件主要是英文硬编码；设计工具是独立 iframe 构建，不能只翻译外层网站。当前不存在完整的本地化框架。

目标：客户明确选择语言，完成阅读、设计、保存、导出和询价，保持品牌和技术含义一致。不增加付费翻译 API 或月费服务。

语言范围（用户确认扩大到主要发达市场常用语言）：
- English (en)：美、英、加拿大、澳大利亚、新西兰及国际采购；不重复生成五套相同英语内容。
- Deutsch (de)、Français (fr)、Español (es)、Italiano (it)、Português (pt-PT)、Nederlands (nl)。
- Svenska (sv)、Dansk (da)、Norsk bokmål (nb)、Suomi (fi)、Íslenska (is)。
- Polski (pl)、Čeština (cs)、Slovenčina (sk)、Slovenščina (sl)、Eesti (et)、Latviešu (lv)、Lietuvių (lt)、Ελληνικά (el)、עברית (he)。
- 日本語 (ja)、한국어 (ko)、繁體中文 (zh-Hant)、简体中文 (zh-Hans)。
- 保留全球市场扩展：العربية (ar)、Português do Brasil (pt-BR)、Русский (ru)。
共 28 个语言/地区版本，英语为现有基线。清单用于业务覆盖，不代表官方国家分类或所有当地语言。阿拉伯语和希伯来语需要从右向左布局；繁简中文和葡萄牙/巴西葡语分别处理。只在对应内容可用并验收后显示可选择入口。

1. 建立术语表、翻译字典及缺失翻译检查。区分产品尺寸和盒内尺寸、材料和工艺、初步预算和正式报价。品牌、客户输入和上传图案不自动翻译。
2. 顶部常驻语言按钮，语言使用本地名称，不用国旗。首次访问提供可关闭的语言面板，可继续英文；浏览器语言只用于推荐，不强制跳转。记住用户选择，存储被禁用时仍可使用。
3. 先完成英文、西班牙文、法文的完整转化路径：导航、首页、产品/行业页、询价、设计工具、错误信息、保存及方案书。未翻译页面明确提示并提供英文，不假装完整翻译。
4. 产品内容、指南、页脚、Cookie/隐私内容逐项本地化。通过字典改写，不使用 DOM 自动替换，避免破坏 React 输入与按钮。
5. 工具语言与外层同步；项目数据保持原样，切换语言不丢设计；询价记录保留客户语言。导出采用所选语言并保留稳定的内部规格字段。
6. 英文 URL 保持；完整翻译页面使用 /es/、/fr/ 等独立 URL。设置正确 lang、互相对应的 hreflang、自引用 canonical、x-default 和 sitemap；未完成翻译不发布空语言页面。
7. 校验桌面/手机、长文本、阿拉伯语从右向左排版、键盘访问、语言切换后保存、询价、导出；完整一批才部署。
8. 第二批德文、意大利文、日文、韩文、荷兰文、繁简中文；第三批其余已列语言。每批都覆盖动态工具、反馈、导出及内容，不将仅有导航翻译的版本标为已完成。

验收：全局切换与首次选择可用；转化路径无语言混杂；语言选择不影响客户数据；表单错误和成功状态已翻译；SEO 标签与实际页面匹配；无新付费服务。多语言不保证排名或询盘增长。

依据：https://developers.google.com/search/docs/specialty/international/managing-multi-regional-sites

## 持续维护约定
采用 i18next / react-i18next 与浏览器语言检测器（MIT，本地打包，不连接收费服务）。公共交互文案位于 lib/locales/interface.mjs；构建前检查两种语言键名和非空值。新增文案必须添加对应语言键，不能复制 DOM 翻译。此检查只覆盖已接入的字典，不能保证所有硬编码网页文本已翻译。
本轮交付是中文服务入口与中文询价链路，完整工具及 28 语言尚未交付。后续需把正文、工具及导出文案逐步抽取到字典，并增设模块覆盖清单。
