# MTT organic acquisition plan — 10 September 2026

## Objective
Help relevant B2B buyers understand the offer, plan a packaging brief and request engineering review. No paid tools, purchased links or fabricated case results.

## Baseline
Search Console page indexing report last updated 4 September: 47 indexed, 30 excluded. Eight discovered/unindexed content URLs; custom-inserts had a historical redirect error. A report is not a live URL test. The gift builder live test passed and indexing was already requested by the user.

## This release
1. Strengthen existing perfume, rigid-box and insert pages with product-specific buying decisions, quote requirements, sample checks and visible concept-image labels.
2. Link each page to relevant existing guides, the gift builder and the quote form; link the tool back to these pages. Preserve canonical URLs.
3. Remove unsupported price ranges, universal volume-saving percentages and categorical protection/recyclability claims in touched pages.
4. Add a consent-respecting builder-entry event to existing analytics; retain quote and lead events.
5. Update sitemap modification dates only for changed content routes.
6. Check static SEO, links, desktop/mobile presentation and existing tool artifact; deploy and verify production.
7. Prepare an English promotion draft and a real-case collection template. No social posts or messages sent.

## Next 4 weeks — owner workflow, not an automated promise
Each week: compare equal 7-day Search Console periods by page, non-brand query and target country. Record impressions, clicks and average position; separate searches containing MTT/mttpackaging. Use analytics only where consent and instrumentation permit; clicks are not confirmed enquiries.
Week 1: inspect the important excluded URLs, request indexing where live tests pass; capture the baseline.
Week 2: publish one verified production case after permission and source evidence are available. Include measured dimensions, actual materials/processes, photos and what was tested. Do not label a concept as a delivered project.
Week 3: share the tool demo through owned channels with UTM tags and adapt one buyer guide using observed query demand.
Week 4: review non-brand discovery and qualified enquiries; expand the strongest topic rather than making near-duplicate pages.

## Acceptance and limits
No promise of ranking, traffic or index timing. Genuine production records/photos are still required for a new real case. External promotion needs user publishing authorization. No new backend, login or recurring service.
